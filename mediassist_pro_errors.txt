Session Fix Log - 2025-10-27
--------------------------------
Fix applied in js/supabase.js:
- __bootApp() now auto-restores session from IndexedDB backup (ma_auth_backup) when localStorage is missing/wiped
- After restoring to localStorage, re-reads session; if still missing and online, attempts refreshSession()
- If offline with backup but cannot refresh, boots app from backup user using cached data (offline-first)
- onAuthStateChange SIGNED_OUT (offline): rescues access-denied screen by booting from backup
- online event: added rescue path to restore/refresh and boot if stuck on access-denied

Root cause addressed: cold start did not consult backup. Recovery only triggered on SIGNED_OUT while offline. Now backup is checked on boot.

Result: Android PWA users with wiped localStorage but existing IDB backup can auto-restore without showing Access Required.
